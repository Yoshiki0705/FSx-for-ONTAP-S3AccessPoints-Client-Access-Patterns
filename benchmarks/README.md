# ベンチマーク

🌐 **言語**: **日本語** | [English](README.en.md)

> **実機の実行には承認が要ります**: 実機での測定は費用が発生しうるため、費用の見込みと後片付けの手順を示して、利用者の承認を得てから手動で実行します。CI では実行しません。

## 方針

- 記録は [docs/templates/benchmark-record.md](../docs/templates/benchmark-record.md) の環境欄をすべて埋めたものだけを `records/` に置きます。
- 測定値は、サンプル測定か本番見積りかを明記します。既定はサンプル測定です。
- 撤去で消える証跡（バケットの中身、使い捨てボリューム上のファイル）は、撤去の前に `records/` へ退避します。

## スクリプト

`scripts/run_benchmark.py` は、既定で何も接続しない dry run です。`make bench-dry-run` で実行できます。実機への接続は、このリポジトリのスクリプトにはまだ実装していません。
