# 確認水準の付け方

マトリクスのセルと、パターン文書の「確認水準と出典」の表は、次の 3 水準のどれかを持ちます。

| 水準 | 付けてよい条件 | 必須の付属情報 |
|---|---|---|
| `M`（`measured`） | 自分で実行して確認した | 測定記録または記入済みチェックリストへのリンク、確認日、そのとき固定していた Hub タグ |
| `D`（`documented`） | 公式ドキュメントに書かれている | 公式 URL、確認日 |
| `C`（`candidate`） | 上のどちらでもない | なし。数値を書かない |

## 規則

- 実測のないセルは必ず `C` にします。`C` のセルには、`C` の 1 文字だけを書きます。
- 検索結果の抜粋は出典にしません。公式ドキュメントのページを開いて読み、書かれている範囲だけを `D` にします。
- 「できない」「対応していない」と書くときは、出典か自分の測定と、成功するはずの対照操作を同じ記録に置きます。
- 確認できたのが設定ファイルの場所だけなら、その項目だけを `D` にし、動作の項目は `C` のままにします。
- `make drift` の `check_matrix` が、`C` の数値、リンクのない `M`、URL と日付のない `D` を失敗にします。
