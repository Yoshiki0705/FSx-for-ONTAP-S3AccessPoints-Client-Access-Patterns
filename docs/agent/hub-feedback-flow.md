# Hub へのフィードバックの流れ

このリポジトリでの確認中に、Hub に記録のない S3 Access Points の制約や挙動を見つけたときの手順です。

1. `drafts/hub-feedback/TEMPLATE.md` をコピーし、`drafts/hub-feedback/<日付>-<トピック>.md` を作る。
2. 観測した事実を 1 文 1 事実で書き、再現手順、環境、成功した対照操作、関係する Hub 文書と節を埋める。
3. 顧客名、アカウント ID、リソース ID、実際のアクセスポイント別名を書かない。
4. このリポジトリの文書には、先に事実として書かない。書く場合は「Hub へ報告済み・未反映」と明示する。
5. 下書きを Hub に出すかどうかは、利用者が決める。エージェントは Issue も PR も作らない。
6. Hub が新しいタグを切ったら、`docs/hub-pin.md` の手順で追従し、下書きの状態を「反映済み（Hub のタグ）」に更新する。
