# 選び方: 用途と要件から選ぶ

このページは、クライアントツールを用途と要件から選ぶための表です。どのツールにも制約があり、表は各選択肢について同じ項目を確認するよう並べます。確認が済んだ内容は [互換性マトリクス](compatibility-matrix.md) に反映されます。現在は全セルが `candidate`（未確認）なので、ここには優劣も数値も書きません。

## 用途ごとの検討対象

| 用途 | 検討する群 | 各選択肢で確認する制約 |
|---|---|---|
| コマンドや定期ジョブで大量のデータを移す | 取り込み・転送（AWS CLI、rclone、s5cmd、AWS Transfer Family、File Mover Express） | 認証方式、マルチパートの扱い、再試行の動作、実行場所の要件 |
| アプリケーションやユーザーにファイルシステムのように見せる | ストリーミング・マウント（Mountpoint for Amazon S3、rclone mount、LucidLink Connect、LucidLink Suite） | 書き込みと削除の可否、整合性の見え方、キャッシュの位置と容量 |
| AI クライアントからツールとして呼び出す | MCP クライアント（Kiro、Claude Desktop） | 設定ファイルの置き場所、サーバの起動方式、認証情報の渡し方 |

## 選ぶときの軸

1. 操作の向き: 取り込みだけか、読み書きの両方か。
2. 見え方: S3 の API のままでよいか、ファイルシステムとして見せたいか。
3. 運用: 商用サポートの有無、導入と更新の手間、実行場所。
4. 費用: ライセンス、データ転送、実機での測定にかかる費用。

## 選択肢の制約を並べる規則

- 各選択肢について、同じ項目の制約を同じ形式で書く。推す選択肢にも制約を書く。
- 制約は、公式ドキュメントの出典か自分の測定の記録があるものだけを書く。確認できなければ `candidate` と書く。
- 「優れている」「劣る」「競合」のように優劣を示す語は使わない。
