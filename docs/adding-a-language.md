# 言語の追加手順

README と主要文書は日本語と英語の 2 言語です。Playbook は 8 言語（ja、en、ko、zh-CN、zh-TW、fr、de、es）で、命名規則を合わせます。追加するかどうかは、リポジトリの保守者が決めます。

## ファイル名の規則

- 日本語が `X.md`、英語が `X.en.md` です。
- 追加する言語は `X.<言語コード>.md` とします（例: `README.ko.md`、`README.zh-CN.md`）。
- 言語コードは Playbook の言語ディレクトリ（`docs/<言語コード>/`）と同じ綴りにします。

## 追加の手順

1. 対象の全文書について `X.<言語コード>.md` を作る。見出しの数と順序、表の列数、注記の数を日本語版と同じにする。
2. 各 README の先頭にある言語切替の行に、新しい言語へのリンクを足す。
3. `scripts/check_parity.py` を、新しい言語の組も照合するよう広げる。広げたあと、片方を欠いた入力で失敗することを `make test` のテストで確かめる。
4. `make all` を通す。
5. 変更を 1 つのコミットにまとめる。
